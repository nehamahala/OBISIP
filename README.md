# OASIS INFOBYTE — Python Programming
## Task 3: Random Password Generator

A browser-based password generator built with Python Flask.

### Features
- Password length control (8–64 in the UI)
- Uppercase, lowercase, numbers and symbols selection
- Secure generation with Python `secrets`
- Guarantees one character from each selected group
- Generate Another option
- Copy-to-clipboard
- Input validation

### Run
```powershell
py -m pip install flask
py app.py
```

The browser opens automatically at:
`http://127.0.0.1:5001`
