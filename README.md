# BodyMetric — BMI Calculator
A polished BMI Calculator built with Python and Flask.

## Features
- Weight and height input
- Instant BMI calculation
- BMI category classification
- Input validation
- Responsive interface
- BMI reference ranges

## Run
```bash
py -m pip install flask
py app.py
```
Open http://127.0.0.1:5003

## Example
60 kg and 170 cm → BMI 20.76 → Normal weight
